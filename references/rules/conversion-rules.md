# 转换规则细则

按脚本实际执行顺序列出。所有规则**只在代码块围栏之外**生效。

## 1. 图片

| 原文 | 结果 |
| --- | --- |
| `<img src="X" width=... class=...>` | `![插图](X)` |
| `<img src="X" alt="说明">` | `![说明](X)` |
| `<img src="X" title="标题">` | `![标题](X)`（alt 为空时取 title） |
| `<img alt="占位图">`（无 src） | `占位图`（保留可读文本，不整枚删除） |

alt 与 title 都为空时用「插图」兜底。

## 2. 链接

`<a href="U">文本</a>` → `[文本](U)`。文本内若还有标签会先被剥掉再填入。

## 3. 强调与删除线

| 标签 | 结果 |
| --- | --- |
| `<b>` / `<strong>` | `**` |
| `<i>` / `<em>` | `*` |
| `<s>` / `<del>` / `<strike>` | `~~` |
| `<u>` | 去除（Markdown 无下划线等价物） |

## 4. 样式与容器标签（去标签留文本）

`<font>` `<span>` `<div>` `<p>` `<section>` `<article>` `<small>` `<big>` `<code>` `<pre>` `<mark>`

只去掉标签本身，**文本原样保留**。因此与 `**粗体**` 嵌套时，去标签后加粗会自动复原。

## 5. 换行

`<br>` / `<br/>` → 行尾两空格的 Markdown 硬换行（保留语义，不是简单删除）。

## 6. HTML 实体

| 实体 | 结果 |
| --- | --- |
| `&nbsp;` | 空格 |
| `&amp;` | `&` |
| `&lt;` / `&gt;` | `<` / `>` |
| `&quot;` | `"` |
| `&apos;` / `&#39;` | `'` |

## 7. 反斜杠转义还原

`\_` → `_`，`\*` → `*`，`\#` → `#`。
（语雀导出常把普通下划线转义成 `\_`，如 `state\_dict` → `state_dict`。）

## 8. 收尾整理

- 空强调 `****`、`** **`、`* *` → 删除
- 行尾多余空白清理，但**保留行尾两空格硬换行**
- 连续 3 个以上空行压缩为 1 个
- 文末保证恰好一个换行

## 不处理的东西

- 围栏（\`\`\` / `~~~`）内的任何内容
- 非 HTML 的组件标记，如 `<Mark bold>`
- 表格结构本身（不重排、不增删行列）
- 图片文件本身（不下载、不校验路径是否存在）
