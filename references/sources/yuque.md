# 语雀导出的特征

语雀是最「脏」的来源：**几乎每个文字片段都被 `<font>` 包裹**。

## 典型形态

```text
<font style="color:rgb(51,51,51)">本节介绍</font>**<font style="color:rgb(51,51,51)">Python</font>**<font style="color:rgb(51,51,51)">的类型。</font>
```

特征：

- `<font style="color:rgb(...)">` 成对出现，一个段落里可能有十几对
- 常与 Markdown 的 `**粗体**` 交错嵌套 —— **去标签后加粗会自动复原，不要手动改**
- 表格里每个单元格也都带 `<font>`
- 图片是 `<img ... class="ne-image">`，通常独占一行

## 处理要点

1. 先 `--scan` 看量级：语雀文档常见单文件上百个 `<font>`
2. `--dry-run --diff` 时重点看**表格行**：确认表头 `| **时间** |` 的加粗还在
3. 图片转 `![]()` 后要提醒用户：语雀导出通常**不带图片目录**，`./images/31.jpg` 多半是坏链
4. 教程类文档的代码块里常有 `<class 'int'>` 这类输出，围栏保护必须生效

## 实测参考

在 9 章 Python 教程 + 入门讲义上：`<font>` × 330、`<span>` × 26、`<img>` × 5；
清洗后代码块外残留 0，其中 1 个文件零改动（无误伤）。
