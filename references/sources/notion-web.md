# Notion / 网页复制的特征

## Notion 导出

- 大量 `<div>`、`<span>` 与内联样式，常成对嵌套多层
- 表格单元格也带标签，且可能有 `<br>` 做单元格内换行
- 链接是 `<a href="...">`，转成 Markdown 链接后需确认 URL 没被相对化

处理要点：

- `<div>` / `<span>` 属于「去标签留文本」，不会丢内容
- 单元格内的 `<br>` 会变成硬换行，注意别破坏表格行结构
- 若导出的是子页面集合，目录是嵌套的，**记得加 `--recursive`**

## 网页复制

- HTML 实体最多：`&nbsp;` `&amp;` `&quot;` `&lt;` `&gt;`
- `<br>` 密集，通常一个段落里好几个
- 常混入 `<b>` `<i>` `<u>` 等强调标签
- 偶尔带 `<section>` `<article>` 等大块容器

处理要点：

- `<u>` 没有 Markdown 等价物，脚本直接去除 —— 若原文靠下划线表意，需人工补回
- 复制进来的内容有时带不可见字符，`&nbsp;` 转成普通空格后排版会更正常
- 图片多为外链 `https://...`，转 `![]()` 后一般可直接渲染
